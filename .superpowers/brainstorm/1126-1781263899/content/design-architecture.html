Datenfluss

useTilt() ← window.mousemove + Ctrl-Key
└─ returns: {rotX, rotY, isTiltLocked}

App.tsx
├─ <div style="--tilt-x:20deg; --tilt-y:-15deg">
│ ← CSS-Variablen auf Wrapper-Div
├─ <BoardPanel isTiltLocked={isTiltLocked} /> ← Blau
└─ <BoardPanel isTiltLocked={isTiltLocked} /> ← Rot

CSS
├─ .board-grid { transform: rotateX(var(--tilt-x)) rotateY(var(--tilt-y)) }
└─ .board-tilt-active .piece → box-shadow Extrusion

useTilt — Verhalten

Ctrl + Drag
Maus-Delta × 0.3 → rotX / rotY ändern
Clamp: −45° … +45°
Ctrl loslassen
Eingefroren — Winkel bleibt. Kein Reset.
Winkel > 30°
isTiltLocked = true → onClick auf Feldern deaktiviert. Cursor: not-allowed.
Winkelberechnung für isTiltLocked:
√(rotX² + rotY²) > 30 — euklidische Distanz, nicht Summe. Bei reiner X-Achse: 30° X = locked. Bei 22° X + 22° Y ≈ 31° = auch locked.

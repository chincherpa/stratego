useTilt API

// src/useTilt.ts
const SENSITIVITY = 0.3; // °/px
const MAX_ANGLE = 45; // clamp
const LOCK_ANGLE = 30; // √(x²+y²) > 30 → locked

interface TiltResult {
  rotX: number;
  rotY: number;
  isActive: boolean; // rotX≠0 || rotY≠0
  isTiltLocked: boolean; // √(x²+y²) > 30
}
Listener auf window: mousedown (Ctrl-Check), mousemove (Delta rechnen), mouseup + keyup[Control] (Drag stoppen). State bleibt eingefroren — kein Reset.

App.tsx Integration

const { rotX, rotY, isActive, isTiltLocked } = useTilt();

<div
  className={`tilt-root${isActive ? ' board-tilt-active' : ''}${isTiltLocked ? ' board-tilt-locked' : ''}`}
  style={{ '--tilt-x': `${rotX}deg`, '--tilt-y': `${rotY}deg` } as CSSProperties}
>
